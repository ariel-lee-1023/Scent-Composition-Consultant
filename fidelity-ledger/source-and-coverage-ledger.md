# Source, coverage, and fidelity ledger

Build date: 2026-09-11. Intended runtime: a practical composition consultant separating physical behavior, perception, and cultural interpretation. This is a selective structural synthesis of eleven requested books, not an exhaustive condensation or a claim to have read every sentence. One reference corresponds to each requested book. The source manifest carries exact filenames, SHA-256 hashes, final corpus spans, declared structure counts, and token measurements without private absolute paths.

## Extraction and recovery

The first-party Books-to-Skill-Refs extractor was preflighted with the bundled Python environment. Markdown used its text-preserving parser. The 770-page Introduction scan yielded only 883 characters in the initial attempt and was rejected by the extractor as lacking a text layer. The supplied Turin Markdown contained image links and page markers rather than prose. The local 219-page companion Turin PDF also lacked a text layer.

Both scans were rendered with PyMuPDF at 144 dpi and processed page by page with Tesseract 5.5.2, English, page segmentation mode 3. All 989 pages produced OCR files; the page-marked recovered Markdown was then passed through the first-party runtime alongside the nine usable requested Markdown sources. The final extraction contains exactly 11 sources, no failures, and approximately 1,606,450 tokens by the runtime's script-density estimator. OCR completion is not full visual verification: molecular drawings, equations, superscripts, unusual names, and table alignments remain vulnerable.

An initial directory expansion also encountered the empty, unrequested Scent and Chemistry Markdown. It was excluded from the final exact source list and contributes no reference or content. Raw sources, recovery text, and temporary files were kept outside the published repository.

Reading used opening/contents probes, heading offsets, and bounded keyword passages. Markdown page markers and image placeholders were removed in temporary reading copies; selected tabularized prose was flattened for readability. The canonical extraction was not edited in place. Some exploratory keyword hits landed in indexes; those hits were not treated as substantive support. No full-corpus read was put into model context. Exact cumulative model input per book was not instrumented; do not interpret source size as model consumption or claim an audited 4× reading ratio. The declared per-book budget provides the planning ceiling, with selective references kept well below it.

## Cross-source synthesis and disagreements

- The three-level diagnostic lens is original synthesis requested by the user, not a named framework attributed to a book.
- Calkin/Jellinek and Curtis/Williams supply controlled accord construction. Ellena questions rigid pyramids and redundant complexity. The core retains temporal overlap and experiment-based balance without making minimalism obligatory.
- The classical Introduction itself states that phases interpenetrate gradually. The core therefore avoids exaggerating the authors' difference into an opposition between literal sequential layers and overlap.
- Physical persistence, perceptual availability, and desired longevity are separated through chemistry, psychophysics, and brief definition. “Add a fixative” is not a complete diagnosis.
- Herz's learning emphasis and Gilbert's individual/genetic variation are complementary only when their scope is kept explicit. No universal emotion-to-material table is created.
- Turin's aesthetic resistance to reducing perfume to memory does not invalidate Herz's memory observations. Turin's molecular vibration is unrelated to Worwood's spiritual vibration; their shared word does not corroborate either mechanism.
- Herman and Burr add cultural and institutional conditions. A note list, house narrative, critical review, and chemical formula remain distinct evidence.

## Budget and loadability

The six-section core is approximately 3,411 body tokens against a 4,125 planning budget and 4,500 hard cap. Eleven references total approximately 23,663 estimated tokens, roughly 1,642–2,978 each. These are deliberately below the computed source-depth targets: the consultant's purpose warrants selection, not padding to reproduce whole books. Tables and named terms have definitions or operational consequences; examples distinguish source reconstructions from new consultation procedures.

The manifest records budgets computed using declared source type. The structural validator independently infers type from runtime formatting, classifying the prose-heavy technical references as text and the Diary's sketch table as technical. Its stricter text ceilings for the three technical books still pass. Both measurements are retained rather than changing the metatool's unrelated working-tree checks. The provisional density heuristic is not a semantic coverage test; no independent density benchmark or calibrated fidelity score is claimed.

## External boundary checks

Official IFRA use guidance was inspected for finished-product concentration basis, constituent contributions, and the distinction between conformity and a complete safety assessment. No ingredient-specific current limit is asserted. Turin's reference cites a 2013 primary human isotope study, a 2015 primary critique, and a 2015 response to establish the existence and levels of the dispute. The later literature was checked through primary publication text/search results; some PMC page opens encountered an access challenge. This is not an exhaustive review or a claim about a final 2026 scientific consensus.

## Maintenance and extension

Keep the canonical runtime at root and source references flat. Add or revise one source-specific reference with a corresponding manifest/coverage update; change the core only when a new distinction changes consulting behavior. Recheck current claims at use time. To expand material-level coverage, revisit the original visual tables or obtain clean licensed editions rather than guessing at damaged text. Re-run the published-layout validator and separate core/reference instruction scans. Record actual tests and sensory observations only when performed; never promote editorial review into a benchmark.
